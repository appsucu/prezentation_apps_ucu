# APPS.UCU — сайт-презентація

Статичний сайт на [Astro](https://astro.build) + TypeScript. Вміст слайдів лежить у Markdown-файлах, розмітка — в Astro-компонентах. Збірка видає один `dist/index.html` (CSS і JS вбудовані) плюс зображення. Його можна публікувати на будь-якому статичному хостингу, в корені або в підпапці.

## Вимоги

Node.js 22.12 або новіший (перевірка: `node -v`).

## Команди

```bash
npm install       # один раз після завантаження проєкту
npm run dev       # локальний перегляд з автооновленням: http://localhost:4321/
npm run build     # перевірка типів і вмісту + збірка в dist/
npm run preview   # перегляд зібраного dist/
npm run check     # лише перевірка (TypeScript + схема слайдів)
```

Якщо поле слайда має помилку (наприклад, неіснуюча назва поля, неправильний `accent` або шлях до неіснуючого зображення), `npm run dev` і `npm run build` покажуть, у якому файлі й полі проблема.

## Структура

- `src/content/slides/` — по одному Markdown-файлу на слайд (`01.md` … `36.md`). Див. `CONTENT_GUIDE.md`.
- `src/content.config.ts` — схема полів слайда (типи й перевірки).
- `src/components/` — блоки слайда: `Slide`, `Cards`, `Chips`, `Groups`, `SlideLinks`, `SlideImage`, `MapPin`, `Overview` (зміст).
- `src/pages/index.astro` — сторінка: шапка, слайди, футер.
- `src/scripts/deck.ts` — навігація: клавіші, коліщатко, `#/slide/N`, зміст, повноекранний режим.
- `src/styles/global.css` — оформлення, кольори й адаптивність.
- `public/` — файли, що копіюються як є: `assets/` (зображення), `favicon.svg`.
- `dist/` — результат `npm run build`. Руками не редагувати: перезаписується при кожній збірці.
- `docs/` — примітки щодо вмісту та перевірок.

## Публікація

Виконайте `npm run build` і опублікуйте вміст папки `dist`. Зміни в локальній копії не оновлюють опублікований сайт автоматично.
